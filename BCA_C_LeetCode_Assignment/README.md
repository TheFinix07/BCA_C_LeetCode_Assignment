# BCA First Semester C Programming - LeetCode Assignment

This repository contains 10 C solutions for beginner LeetCode problems, prepared for the BCA first-semester assignment.

## Problems
1. Two Sum — arrays and searching
2. Reverse String — strings and pointers
3. Valid Palindrome — strings and character handling
4. Remove Element — in-place array modification
5. Merge Sorted Array — arrays and pointers
6. Best Time to Buy and Sell Stock — greedy algorithm
7. Contains Duplicate — array searching
8. Move Zeroes — two-pointer technique
9. Majority Element — Boyer-Moore voting algorithm
10. Binary Search — searching algorithm
