ASSIGNMENT QUICK START

1. Extract this ZIP to a folder on your PC.
2. Create/sign into your LeetCode account: https://leetcode.com/
3. Open each problem listed in README.md.
4. Select C as the language, paste the corresponding .c solution, and click Submit.
5. Confirm the result is Accepted. Learn what each function does; comments summarize the approach and complexity.
6. Create a GitHub repository named BCA-C-Programming-LeetCode.
7. Install/open GitHub Desktop: https://desktop.github.com/
8. In GitHub Desktop: File > Add Local Repository (if the extracted folder is not already a Git repository, choose Create a Repository).
9. Publish the repository to GitHub. Choose Public if your instructor needs to view it.
10. Commit changes with a meaningful message, e.g. "Add 10 C LeetCode solutions".
11. Create a branch called documentation, edit README.md on that branch, commit, then create a Pull Request on GitHub and merge it into main.
12. Submit your public repository link.
